# 1C Agent Harness

Минимальный универсальный харнест для работы кодовых агентов с выгруженными исходниками 1С в Linux-воркспейсе.

## Зачем

Сделать незнакомую — в том числе кастомную и унаследованную — конфигурацию 1С понятной для кодового агента: дать ему воспроизводимый способ исследовать код, внести ограниченное изменение и показать проверяемый результат.

## Принцип

KISS: добавляем только то, что требуется подтверждённым рабочим сценарием. Универсальность достигается простым файловым и CLI-контрактом для любого кодового агента, а не поддержкой всего инструментария и всех вариантов 1С.

## MVP

- инвентаризация выгруженных исходников;
- навигация и поиск по BSL-коду;
- точечное изменение существующих модулей;
- доступные статические проверки;
- понятный diff, протокол выполненных проверок и явные ограничения результата.

## Не входит в MVP

- подключение к живой информационной базе;
- EDT, удалённый MCP и транспорт между средами;
- изменение метаданных, форм, СКД, ролей и RLS;
- runtime-отладка и интеграционные тесты;
- абстракции и совместимость «на будущее».

## Начальная среда

Hermes с Codex CLI, Linux-воркспейс и исходники конфигурации на файловой системе.

## Статус

Сбор брифинга и определение минимального сквозного сценария.
