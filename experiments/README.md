# Experiment templates

Скопируйте `experiment.json.example`, `questions.json.example` и `adjudication.json.example` в новый `.local/experiments/<id>/`, замените значения и вычислите SHA-256. Example-файлы намеренно содержат placeholders и не являются готовым экспериментом.

Исполняемый порядок описан в [`docs/experiment-runbook.md`](../docs/experiment-runbook.md).
