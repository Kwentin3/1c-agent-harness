# Подтверждённая граница совместимости

## Проверено

| Capability | Статус | Доказательство |
|---|---|---|
| Официальная Linux-платформа 1С `8.5.1.1150` | работает нативно | `CREATEINFOBASE`, `LoadCfg`, полный hierarchical `DumpConfigToFiles` |
| Jet 1.0.3.1, `CompatibilityMode=Version8_3_24` | работает нативно | 5099 файлов, повторные побайтово одинаковые выгрузки |
| SDMS 0.1.1.0, `CompatibilityMode=Version8_3_26` | работает нативно | 2581 файл, 646 BSL, две одинаковые выгрузки |
| Static evidence harness поверх полного snapshot | работает нативно | manifest/content ID, locator verification, comparison и seal |
| Ошибки locale в кириллических путях | проверенный fail-closed fallback | UTF-8 locale; preflight отклоняет пути с `?` |
| Неполный набор файлов snapshot | работает с ограничениями | обязательны `Configuration.xml` и `ConfigDumpInfo.xml`; нативный `LoadConfigFromFiles` остаётся сильнейшей проверкой полноты |

Все опубликованные результаты относятся к XML format `2.21`, сформированному
указанной платформой. `CompatibilityMode=Version8_3_24/26` внутри конфигурации не
доказывает запуск на платформе 8.3.

## Не проверено

В workspace нет дистрибутива или установленного исполняемого файла целевой старой
платформы: найдена только `8.5.1.1150`. Учебный дистрибутив 8.5 получен после
персонального принятия лицензии; воспроизводимого законного источника точной
старой версии без нового лицензионного/интерактивного precondition нет.

Поэтому пока нельзя подтвердить:

- native load/dump на конкретной старой версии 8.2/8.3;
- формат snapshot, созданный старой платформой;
- расхождения parser/tool по версиям;
- полный legacy capability envelope.

Минимальный внешний prerequisite для продолжения этапа legacy: точная версия и
законно предоставленный Linux-дистрибутив целевой старой платформы либо уже
созданный ею полный read-only snapshot с provenance. Форк не предлагается: ни
одного дефекта, требующего форка, на старой платформе ещё не воспроизведено.
